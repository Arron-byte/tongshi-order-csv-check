# Editable Word Conversion Sample

This two-page sample shows how a text-based PDF can be rebuilt as an editable Word document. Both files use fictional workshop records.

- [Source PDF](workshop-record-source.pdf)
- [Editable Word document](workshop-record-editable.docx)
- [Verification results](verification.json)

The Word file preserves both pages, section headings, two native tables and their 36 cell values, and the shared footer. It was reopened and exported in Microsoft Word for visual comparison. A separate copy was edited and reopened to confirm that a table cell can be changed without changing the original.
